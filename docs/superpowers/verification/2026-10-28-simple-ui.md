## Summary

## How it works (for reviewers)

- **Navigation** (`components/control-center.tsx`): four places plus Quick capture and the account menu. Every existing `?view=` address still opens its screen; a plain `/` opens Home. Advanced tools show "Back to Advanced", and their load-failure screens offer "Return to Advanced".
- **Home** (`components/home-view.tsx`, `components/home-briefings.tsx`): the heading, Capture and plain project cards paint from the saved workspace in the startup code. The briefing part loads as a deferred module, using the same feed and save path as Mission control (`components/briefing-feed.ts`, extracted unchanged from `mission-control.tsx`). "Brief this project" uses the keep-current assistant, otherwise the assistant of the last briefing, otherwise the first one that is ready. Its disabled reason comes from `lib/project-action-reasons.ts` (`components/briefing-actions.ts`).
- **Project page** (`components/projects-view.tsx`, `components/project-briefing.tsx`): the briefing first, then the unchanged `ProjectFolders`, then the plan inside a fold that renders only when opened (bulk task tools load only then), then "About this project" (goal, framing, Edit project, Archive/Restore, technical links).
- **Needs you** (`components/needs-you-view.tsx`): every briefing "needs you" line plus reviews, approvals, runs to check, overdue work, pinned work from earlier weeks and waiting captures, grouped by project. It only navigates; it never changes anything.
- **Advanced** (`components/advanced-view.tsx`): grouped list of all tools with one-line descriptions, and connection details.
- Briefing views read saved briefings but not saved technical analysis reports (`lib/dashboard/feed.ts` `reports:false`), so those stay unread until Mission control or the Repositories technical fold asks for them.

## Behaviour notes

- A briefing your PC has finished is still saved automatically, exactly as the Today page did. Because Home is now the first screen, that save happens when Home (or a project page, Needs you or Mission control) is open, instead of only when Today was opened.
- While Home, a project page or Needs you is open, they check the PC connection every 45 seconds (every 10 seconds while your PC is working) and re-read saved briefings about every 90 seconds — the same pace the Today page used. They do not read saved technical reports.
- The plan fold on a project page remembers being open for the rest of the browser tab's session.
